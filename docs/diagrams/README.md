# Diagrams

[`generate.cjs`](generate.cjs) writes every SVG here and in `flows/`. Edit it, then run this from the repository root. It has no dependencies.

```bash
node docs/diagrams/generate.cjs
```

Each diagram has one question as its title, a few nodes and one sentence as its point. Details belong in [Engineering Flows](../ENGINEERING_FLOWS.md), not in the picture. The SVGs follow the viewer's light or dark theme.
